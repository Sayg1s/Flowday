# Flowday

Flowday — локальный PWA-планировщик времени и задач в стиле Structured.

## Запуск
- Для быстрого теста откройте `index.html` в браузере.
- Для установки на телефон и полноценного офлайн-режима разместите все файлы папки на HTTPS-хостинге (например, GitHub Pages).
- Service Worker и установка PWA не работают при открытии через `file://`.

## Что есть в этой версии
- Расписание дня и календарь с выбором дат.
- Живая линия текущего времени и обновляемая сводка «Сейчас».
- Прошедшие события визуально приглушаются.
- Drag & drop события на другую дату в календаре.
- Долгое нажатие на событие на телефоне предлагает перенести незавершённые задачи.
- Приоритеты событий, чек-листы и прогресс выполнения.
- Статистика дня: запланированное время и выполнение задач.
- Светлая и тёмная темы с мягкими розовыми акцентами.
- Заметки, списки, ДЗ/проекты, сведения, история событий.
- Экспорт и импорт резервной копии JSON.
- Локальное хранение данных в localStorage.

## Файлы
- `index.html` — приложение, стили и логика.
- `manifest.webmanifest` — параметры установки PWA.
- `sw.js` — офлайн-кэш (версия кэша обновлена).
- `icon.svg` — иконка приложения.
